## 💡 关键技术点

### HTML转WXML对照表
| HTML | WXML | 说明 |
|------|-------|------|
| `<div>` | `<view>` | 容器元素 |
| `<span>` | `<text>` | 文本元素 |
| `<img>` | `<image>` | 图片元素 |
| `class=` | `class=` | 类名（相同） |
| `onclick=` | `bindtap=` | 点击事件 |
| `{{ }}` | `{{ }}` | 数据绑定（相同） |

### CSS转WXSS注意事项
1. **单位转换**: `px` → `rpx`（响应式像素，750rpx = 屏幕宽度）
2. **选择器限制**: 不支持通配符`*`、不支持部分伪类
3. **动画**: 使用`animation`或`wx.createAnimation`
4. **尺寸**: 使用`rpx`实现响应式布局

### JavaScript转小程序Page逻辑
```javascript
// HTML中的逻辑
function showCityInfo(city) { ... }

// 小程序中的逻辑
Page({
  showCityInfo(e) {
    const city = e.currentTarget.dataset.city
    this.setData({ currentCity: city })
  }
})
```
